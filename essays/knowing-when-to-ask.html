Knowing When to Ask: Self-Gated Clarification for Language Agents

Most agents either over-ask or never ask at all. The right question is not how often an agent asks. It is where it asks, and whether asking competes with acting on the same scale.

Jae Oh Woo

Hierarchical agents fail at intermediate decisions. A taxonomy classifier picks the wrong subtree at depth two and the rest of the trajectory inherits the error. A tool-using agent commits to a query before realizing it is missing a key constraint. The pattern is the same: the agent commits to a branch without recognizing that it lacks the information needed to commit at all. Final-answer accuracy tells you that the system failed, not at which step it should have stopped and asked.

The standard remedies bolt clarification onto the side of the policy. A confidence threshold says "ask if uncertain." A prompt instruction says the same thing in words. A sampling-based trigger asks when several runs disagree. These share a flaw: asking is decided outside the choice of what to do next, by a different signal on a different scale. The agent never weighs "ask" and "act" against each other on equal footing.

Our recent paper, accepted at the ACM CAIS 2026 Workshop on AI Agents for Discovery in the Wild, proposes a different framing, which we call ActionRating: put clarification inside the action space, on the same ordinal rating scale as every other branch. Asking does not get a special pathway. It competes.

Self-Gated Clarification
"Ask" lives in the action space itself
Same 0 to 100 ordinal scale as navigation actions
Decided locally at every branch
Asking competes with acting

Where clarification lives changes which questions you can answer about it.

A Concrete Case: Cough Drops

The test bed is U.S. tariff classification. Every imported good gets a 10-digit Harmonized Tariff Schedule (HTS) code, and the schedule is a tree of 30,000+ nodes across 5 levels: each pair of digits narrows the path from chapter to final statistical line. We model navigation as a Markov decision process over this tree, with five action types: traverse to a child, backtrack, jump, confirm, and need_clarify(q), which asks a question. The input is a free-text product description, which is almost always incomplete.

Take one record: sugar confectionery cough drops containing 10 mg of menthol. The baseline agent reads "10 mg per dose" and commits to pharmaceuticals. Everything after that is a careful elaboration of a wrong turn. With ActionRating, at that early node clarification scores 68 while the best branch scores 31. The agent asks whether the product is put up in measured doses or for retail sale as a medicament, learns that it is confectionery sold at retail, and routes correctly.

That is the case where asking is obviously right. The harder case is when the agent already has a good guess. For a butadiene-based copolymer, the top action is "polymers of olefins" at 72, with clarification second at 48. The question, "Is butadiene considered an olefin for classification purposes?", targets a convention, not chemistry: butadiene is chemically a conjugated diene, but classification practice treats its polymers as olefin polymers. Without the answer, the automated system applies strict chemistry and misroutes to "other resins". A good agent needs to ask in both situations, and they are not the same situation.

Why a Separate Trigger Is Not Enough

When the decision to ask lives outside the decision to act, two problems stay unsolved. First, help-seeking is not structurally observable: a low scalar confidence looks the same whether every branch is bad or one branch is good but not good enough. Second, it confounds where help was sought with what help was received. If an agent that asks more ends up more accurate, you cannot say whether it asked at better moments or just got better information. Most evaluations of clarifying agents report end accuracy and stop. I think that is the wrong unit of analysis, because it gives no credit or blame to the decision about when to ask.

The Core Move: Asking on the Same Scale as Acting

At each step, the agent lists its top-K candidate actions, including need_clarify, and scores each from 0 to 100 with a one-sentence rationale, in the same navigation call. If clarification appears with a score at or above a threshold τ, a sub-agent asks the question, the answer is added to the observation, and the agent re-rates its options at the same node. Otherwise it takes the top action. The outer loop does not change.

There is still a threshold, and I want to be clear about that. What changes is what it applies to: τ is not a cutoff on a confidence computed outside the decision, but a floor on how highly the agent itself rates asking, next to the moves it could make. That makes two structurally distinct modes visible, read directly from the rank of the clarification action:

Bolting a clarifier onto a policy tells you how often the agent asks. Putting clarification inside the action space lets you ask where the agent asks, and whether asking is competing with the right alternatives.

Mandatory clarification. Clarification is ranked first; no navigation branch scores above it. The agent is not picking among acceptable options. It is saying none is good enough. The cough drops are this mode.

Opportunistic clarification. A navigation action leads, but clarification still ranks in positions 2 to K at or above τ. The agent has a candidate, and still judges a targeted question worth asking. The copolymer is this mode.

The definition depends only on rank, not on any claim about what the agent "really" knows. In practice, mandatory questions tend to ask for missing essential attributes (composition, use, form) at shallow levels, and opportunistic questions ask about conventions and threshold values deeper down.

What the Experiments Compare

The main comparison uses Claude Opus 4.6 on CBP-NY, 1,181 products from public U.S. Customs rulings. The baseline picks actions greedily without scoring or gating. Three contrasts test the obvious alternatives: a prompt instruction to ask when unsure, a trigger that asks when three sampled actions disagree (Self-Consistency, N=3), and a rating-only ablation that keeps the scoring step but sets τ=101 so clarification never fires.

Regime shift: mandatory clarification falls from 35.2% to 13.9% of records, opportunistic rises from 0% to 88.7%
Information-Seeking Effectiveness rises from 50% to 74%, even though the agent asks about 6× more often
10-digit accuracy 50.8% → 67.0% (+16.2pp) under controlled answers: an upper bound, not a deployment estimate
With automated answers accuracy falls by 18.8pp, yet the mode split and ISE ranking are preserved: where to ask is separable from what comes back

Claude Opus 4.6 on CBP-NY (N=1,181), τ=10. The pattern also holds across four LLM families and two further benchmarks.

Information-Seeking Effectiveness (ISE), the fraction of clarification interactions followed by a correct next navigation step, is the metric I find most useful. It does not ask "did asking help on average?" It asks "when this agent chose to ask, did the next move land on the correct path?" Because answer quality is held fixed, a change in ISE reflects a change in where the agent asked.

Here is the part that is easy to misread. At τ=10 the agent asks about six times as often as the baseline (2.4 versus 0.4 questions per record), and ISE still rises from 50% to 74%; both modes reach about 75%. So volume does go up, but not indiscriminately: at τ=1 the agent asks 5.9 times per record and ISE falls to 62%. More asking and better asking come apart, which is the clearest evidence that the mechanism locates the right places to ask.

Key Insight

The interesting variable is not whether agents ask, but where in the trajectory they ask. Even when the agent was already off the correct path at the moment it asked opportunistically, its next step was correct 67.3% of the time (83.6% when on the path). These questions steer trajectories back, not only confirm easy ones.

None of the contrasts produce this pattern. The rating-only ablation lands slightly below the baseline (−0.9%) and produces no opportunistic events, so scoring alone is not what helps; acting on the score is. At 10 digits, ActionRating is 7.5 points above Self-Consistency. Navigation steps stay flat (5.4 to 5.7 across thresholds): gating changes where the agent seeks help, not how it walks the tree. The pattern also transfers across Claude, DeepSeek, GPT-OSS and Qwen3, and to the ATLAS and HSCodeComp benchmarks with τ locked from CBP-NY before either was evaluated.

Separating Where from What

The framing allows a cleaner decomposition: keep the policy that decides where to ask, and change the quality of the answers. The controlled channel simulates a knowledgeable product owner who states attributes such as composition, intended use and manufacturing method, with classification codes masked. The degraded channel generates answers from the product description alone.

With degraded answers, ActionRating loses nearly all its 10-digit gain (67.0% to 48.2%, an 18.8-point drop), while the baseline barely moves (50.8% to 49.2%). ISE falls too, from 73.7% to 56.2%. Yet the mandatory and opportunistic split and the ranking of ISE across thresholds are preserved. The agent still finds the states where it needs help; without a knowledgeable respondent it cannot turn that help into a correct code.

Does the controlled channel leak answers? An audit of all 2,875 question and answer pairs found that 80% of answers are plain product attributes, and only 23 pairs (0.8%) directly affirm or deny a classification criterion. Those 23 produce lower ISE than plain attribute answers (62.5% versus 76.2%). So I read the +16.2 points as an upper bound on what better localization could unlock, not a deployment estimate. Where to ask and what help comes back are separable problems, and this paper isolates the first.

The Price of a Question

Asking is not free. ActionRating raises cost from 6.0 to 10.4 LLM calls per record, a 73% overhead. Self-Consistency needs about 19 calls for an 8.7-point gain, below the ActionRating frontier. In deployment there is also a human cost that call counts miss: every question is something a person must read and answer, and opportunistic mode can run several rounds in one step.

The threshold is where this tradeoff is set. Between τ=50 and τ=30, the opportunistic rate jumps from 9.7% to 51.9% of records and accuracy from 51.2% to 59.8%. At τ=1 accuracy is higher still (72.5% versus 67.0% at τ=10), but the agent nearly always asks and ISE drops to 62%. We report τ=10 because the contribution is localization, and it maximizes that signal at moderate cost. A team with a patient expert on the other end might choose differently. The protocol matters more than the number: sweep τ once on in-domain development data, lock it, then evaluate on held-out data.

What This Does Not Show

The accuracy numbers are upper bounds. Realistic answer sources would yield smaller gains, and we have not yet varied answer quality across the intermediate range. One domain. Three HTS benchmarks share a taxonomy; ICD-10 coding or legal statutes would need a rebuilt domain layer, even if the measurement protocol carries over. The scores are not calibrated. The method needs meaningful ordinal scores, not probabilities, and τ may need re-tuning per model. The modes are observational. They come from the agent's own ratings, not from ground truth about what it knew. Evaluation also uses English descriptions only.

The open question I care most about is an answer-source ladder: the same agent against the controlled channel, then retrieval, weaker models and noisy human-like responses. The separability result predicts the information-seeking pattern stays stable while accuracy falls. If so, help-seeking splits into three parts that can be studied one at a time: where to ask, what to ask, and who answers.

Why This Connects to the Rest of the Agenda

The thread running through my recent work is the same: AI systems should not only answer; they should know when their reasoning is reliable, when uncertainty is high, and when decisions should be deferred. The conformal social choice essay asks when a multi-agent debate result is safe to act on, and when it should escalate to a human. The probabilistic VC essay asks when a model's self-evaluation can be trusted to generalize. The structural uncertainty essay asks when surface agreement is hiding underlying instability.

This essay's question is the agentic version: when, in the middle of a task, should the agent stop committing and ask? The conformal work defers at the end of a decision, with a coverage guarantee from a calibration set. Self-gated clarification defers mid-trajectory, using uncalibrated ordinal scores. That is weaker evidence, but I think it fits the job: at each node the agent only needs to compare its options, including asking, and a ranking is enough for that. Whether calibrated deferral can be brought to intermediate nodes is a question I would like to see answered. And the rating-only ablation echoes the self-evaluation work: self-assessment is useful when it is tied to a decision, much less so as a report.

Treating asking as just another rating on the same scale is what makes "knowing when to ask" observable and measurable rather than a hidden heuristic. A system that always answers is brittle; a system that asks every step is unusable. A system that asks where it should is the one worth building.
